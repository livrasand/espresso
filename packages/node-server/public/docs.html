Espresso Repositories Profile API docs

API Documentation

Repository browsing API for gitGost over ESP32 storage nodes.

Espresso exposes a repository browsing API under the /api/gg prefix and Git smart-HTTP under /:owner/:repo.git/.... No exposed ports, no passwords.

Go to dashboard

Endpoints

Directory tree

GET /api/gg/repos/:owner/:repo/tree?path=

Lists the contents of a directory inside the repository.

Raw file content

GET /api/gg/repos/:owner/:repo/raw?path=README.md

Returns file content as text/plain.

Repository info

GET /api/gg/repos/:owner/:repo/info

Basic repository metadata.

Branches

GET /api/gg/repos/:owner/:repo/branches

List of branch names.

Tags

GET /api/gg/repos/:owner/:repo/tags

List of tag names.

Topics

GET /api/gg/repos/:owner/:repo/topics

Discovery categories/tags (currently empty until topic storage is added).

Commits

GET /api/gg/repos/:owner/:repo/commits

List of commit SHAs.

Authentication

Session token

Send X-ZKP-Token: <token> on management endpoints and authenticated browsing.

Anonymous browsing

Works without a token in trusted-network mode (no API key configured on the server).

Git smart-HTTP

Clone / fetch / push

GET /:owner/:repo.git/info/refs?service=git-upload-pack
POST /:owner/:repo.git/git-upload-pack

Add X-ZKP-Token to Git HTTP requests.
